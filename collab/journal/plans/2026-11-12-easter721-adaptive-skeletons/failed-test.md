# 행동 시나리오

- [x] 목록 이동 대기는 보이는 영역에 충분한 카드를 표시하고 추가 로딩은 두 카드로 유지한다.
- [x] 검색 제출 대기는 화면을 채우고 인기 기사는 최대 세 개와 실제 순위 수에 맞추며 추가 로딩은 제한한다.
- [x] 지도 초기 대기와 기사 데이터가 있는 SDK 대기에 화면 너비에 맞는 카드를 표시하고 짧은 화면에서 실제 카드 높이를 따른다.
- [x] 네 화면 크기에서 보이는 영역, 상태 알림, 실제 데이터 전환을 브라우저에서 확인한다.

검색 주소 직접 진입은 NoJS 본문을 유지하기 위해 기존처럼 서버 응답을 기다린다. 검색 로딩 경계를 추가하지 않았다.
