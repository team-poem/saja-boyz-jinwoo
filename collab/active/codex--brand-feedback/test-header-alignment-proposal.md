# 테스트 경로 헤더 정렬 — 정정 제안

## 앞선 제안의 오류

`test-header-fix-proposal.md`는 경로가 섹션 제목에 있으면 충분하다고 잘못 판단했다. 소바야 파서는 실제로 코드 블록의 `// file:` 주석을 필수로 사용한다. 주석을 제거한 버전은 재승인 파싱 단계에서 거절되었고, 재승인 상태는 변경되지 않았다. 기존 구현과 통과한 120개 테스트는 보존되어 있다.

## 정확한 변경 두 곳

1. `failed-test.md`의 두 번째 Node 섹션에서 앞서 제거한 다음 한 줄을 원래 자리로 복구한다.
2. `src/features/map/ui/map-home/map-articles.test.ts` 맨 위에 같은 한 줄을 추가한다.

```ts
// file: src/features/map/ui/map-home/map-articles.test.ts
```

그 외 명세·테스트 본문·이름·기대값·fixture·전체 테스트 명령은 바꾸지 않는다. 완료 체크포인트도 유지한다. 새로운 테스트나 의존성은 추가하지 않는다.

## 사전 검증

수정된 두 파일의 임시 복사본으로 소바야 실제 `plan.awk` 파서를 실행해 4개 항목과 대상 경로를 확인하고, 세 지도 테스트의 승인 헤더가 대상 파일의 시작 부분과 바이트 단위로 일치함을 확인한다. 테스트 함수 본문은 현재와 동일하다.

## 승인 후

위 두 줄만 반영하고 공식 `approve.sh --replace`로 재승인한다. 나머지 두 항목, 최종 122개 전체 gate, 기존 브라우저 검사 45개의 소스 동일성, 독립 리뷰 후 dev PR까지 진행한다.
