# 상태 안내 문구·표현 대조

새 제목/도움말은 실제 정보나 오류 사유를 대체하지 않고 위계를 만든다. 아래 표의 기존 상태 문구는 화면의 사유/상태 본문으로 한 번만 표시한다. API 내용·기사 원문·제보 상태와 로딩 접근성 라벨은 그대로다.

| 화면/상태 | 제목 또는 기존 상태 | 보완할 도움말·행동 |
| --- | --- | --- |
| 위치 오류 | 위치를 한 번 더 확인할까요? | spec의 오류별 새 도움말 + `위치 다시 시도`, 조회 중 중복 잠금 |
| 지도 SDK 오류 | 지도를 다시 펼쳐볼까요? | 기존 지도 오류 사유와 `연결을 확인한 뒤 다시 눌러주세요.` + 기존 다시 시도 |
| 지도 설정 미제공 | 지도를 잠시 열 수 없어요 | 관리자 설정 안내와 기사 목록/검색으로 이어지는 실제 링크. 사용자에게 SDK/API 설정값을 노출하지 않음 |
| 기사 좌표 조회 실패 | 주변 소식을 다시 이어볼까요? | 기존 기사 위치 실패 사유 + `지도는 그대로 둘게요. 잠시 후 다시 불러와 주세요.` + 기사 위치 다시 불러오기 |
| 지도 기사 없음 | 다른 동네 소식도 살펴볼까요? | 기존 위치 확인 기사 없음 설명 + 전체 기사 목록 |
| 지도 기간 결과 없음 | 기간을 조금 넓혀볼까요? | 기존 선택한 기간 기사 없음 설명과 기간 변경 제안. 안전/무사고로 단정하지 않음 |
| 기사 목록 최초 실패/아카이브 실패 | 주변 소식을 다시 이어볼까요? | 기존 기사 실패 사유 + 연결 확인/다시 시도. 기존 오류와 빈 목록 구분 |
| 목록 추가 페이지 실패 | 이어지는 소식을 다시 볼까요? | 기존 추가 기사 실패 사유 + `읽던 내용은 그대로 있어요.` + 기존 재시도, offset·중복 제거 유지 |
| 검색 최초 실패 | 검색을 다시 이어볼까요? | 기존 검색 실패 사유 + `검색어는 그대로 두었어요. 한 번 더 눌러주세요.` + 기존 같은 검색어 재시도 |
| 검색 추가 실패 | 이어지는 검색 결과를 다시 볼까요? | 기존 추가 기사 실패 사유 + 기존 카드/검색어 유지 안내와 재시도 |
| 검색 빈 결과 | 검색 결과가 없어요 | `다른 키워드로 동네 소식을 찾아보세요.` |
| 최근 검색 없음 | 최근 검색어가 없어요 | `첫 검색으로 동네 소식을 찾아보세요.` |
| 기사 목록 없음 | 아직 수집된 기사가 없어요 | `지도나 검색에서 다른 소식도 살펴보세요.` + 실제 지도/검색 링크 |
| 사건 필터 빈 결과 | 조건에 맞는 사건이 없어요 | `검색어나 필터를 조금 바꿔볼까요?` |
| 상세 조회 실패 | 이 소식을 다시 열어볼까요? | 기존 기사 실패 사유 + 같은 기사 재시도와 목록/지도 복귀 유지 |
| 상세 404 | 기사를 찾을 수 없어요 | `링크를 확인하거나 목록에서 다른 소식을 살펴보세요.` + 기존 목록 복귀 |
| 전역/기능 오류 | 다시 이어서 볼까요? | 기존 오류 사유와 기존 reset/retry. 네트워크·설정·잘못된 응답 구분 유지 |
| 제보 불확실/실패 | 제보 상태를 다시 확인해 주세요 | 기존 불확실/실패의 정확한 문구 유지. 성공으로 표현하지 않으며 입력·첨부 보존, 기존 제출/재시도 흐름 유지 |
| 제보 접수 성공 | 제보가 접수됐어요 · 접수번호 | `소식을 전해주셔서 고마워요.`를 보조 문구로 사용. 검증된 receipt만 성공 처리 |
| 전체 404 | 페이지를 찾을 수 없어요 | `주소를 확인하거나 지도로 돌아가 다른 소식을 살펴보세요.` + 기존 탐색 링크. 낡은 `개발 준비 화면`/`사건 데이터는 아직 연결되지 않았습니다` 제거 |

## 표현 기준
- 빨강은 작은 아이콘/행동/얇은 테두리에 집중하고 본문은 충분한 대비를 유지한다. 모든 문장에 흉흉 이름이나 이모지를 붙이지 않는다.
- 이미 `~없어요/~못했어요`로 쓰인 정확한 상태는 유지해 단순한 문구 일괄 교체보다 읽기 쉬운 위계와 다음 행동을 보완한다.
- 미지원 분류/상태 필터는 현재 미제공 사실을 유지한다. 추후 제공 시점이나 현재 사건의 심각성을 임의로 만들지 않는다.
- 이미지 없음/AI 생성/기사 발행일/대표 좌표 경고는 사실을 설명하는 짧은 표기를 유지한다.
