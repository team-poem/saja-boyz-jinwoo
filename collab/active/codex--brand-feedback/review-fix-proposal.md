# 독립 리뷰 보완안

## 발견한 문제

- 320×568처럼 좁고 낮은 화면에서는 위치 안내가 하단 내 위치 버튼·기사 카드와 겹칠 수 있다. 기존 브라우저 검증에는 이 높이가 빠져 있었다.
- 위치 재시도를 누르면 안내와 버튼이 즉시 제거되어 키보드 포커스가 유실된다.

## 수정 범위

기존 명세의 위치 재시도·안내 가독성 범위 안에서 소바야로 지도 안내 영역을 하단 컨트롤과 겹치지 않도록 제한하고 필요할 때 내부 스크롤을 제공한다. 재시도 중에는 안내와 액션을 유지하고 중복 요청은 차단한다. 재실패 시 재시도 액션, 성공 시 안정적인 내 위치 컨트롤로 키보드 포커스를 복원하되 다른 곳으로 이동한 사용자 포커스를 빼앗지 않는다.

기존 122개 테스트는 유지하고 `review-focus-test.ts.txt`의 정확한 테스트 1개만 소바야 계획에 추가한다. 명세·API·의존성·기존 테스트 본문과 기대값·포털 구조는 변경하지 않는다. 최종 테스트는 123개다.

## 정확 테스트

`review-focus-test.ts.txt`의 `mapLocationRetryPreservesFocusAcrossPendingFailureAndSuccess`를 기존 map-home.test.ts에 추가한다. 기존 파일과 동일한 // file: 경로 및 helper 헤더를 사용하는 별도 계획 섹션을 추가하며, 앞선 완료 항목은 유지한다.

- 대기 중 버튼이 연결된 상태이고 포커스가 지도 영역 안에 있는지 확인.
- 재실패 후 재시도 버튼으로 포커스 복원 확인.
- 성공 후 안내 제거와 내 위치 버튼의 활성화·포커스 확인.
- 기대값을 완화하거나 테스트를 생략하지 않음.

초안을 기존 파일에 추가한 메모리상의 전체 소스로 타입·ESLint 오류 0개·Prettier를 검사했다. 실제 소바야 파서에서 5개 계획 항목과 대상 파일 헤더 일치도 확인했다. 실제 보호 테스트는 아직 수정하지 않았다. 승인 후 소바야 구현, 320×568 및 기존 화면 브라우저 대조, 123개 전체 gate·독립 리뷰, 커밋·푸시·dev PR까지 진행한다.
