# 승인 테스트 헤더의 경로 주석 수정안

## 원인

전체 테스트 120개는 통과했으나, 소바야가 두 번째 항목 체크포인트 후 승인 헤더와 기존 테스트 파일의 시작 부분을 비교하면서 중단했다. 초안 작성 때 아래 경로 주석까지 실행 헤더로 들어간 것을 놓쳤다.

## 정확한 변경

루트 `failed-test.md`의 두 번째 Node 섹션에서 다음 한 줄만 제거한다. 해당 섹션 제목에 같은 경로가 있으므로 대상 파일 지정은 유지된다.

````diff
 ## Node — src/features/map/ui/map-home/map-articles.test.ts
 
 ```ts
-// file: src/features/map/ui/map-home/map-articles.test.ts
 // @vitest-environment jsdom
````

명세, 테스트 4개 본문·기대값·이름·순서, 기존 테스트와 fixture, 전체 테스트 명령은 변경하지 않는다. 실제 테스트 파일에 주석을 끼워 넣거나 소바야의 보호 검사를 우회하지 않는다.

## 승인 후 절차

헤더 한 줄만 수정하고 기존 구현·완료 체크포인트를 유지한 채 소바야 공식 재승인 절차로 등록한다. 전체 122개 테스트, 빌드 및 브라우저 증거의 소스 동일성, 독립 리뷰를 확인하고 dev PR까지 진행한다.

## 현재 검증

- 전체 120개 테스트 통과.
- 제품 소스 빌드·포맷·타입 검사 통과. 린트 오류 0개, 기존 경고 3개.
- 실제 Chrome 브라우저 검사 45개 통과, 18개 화면 캡처.
- 헤더에서 경로 주석을 제외한 나머지는 기존 파일 시작 부분과 동일함을 확인.
