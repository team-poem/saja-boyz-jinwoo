# 위치 재시도 로딩 표현 중복 보완

## 독립 리뷰 결과

기존 작은 화면 겹침과 재시도 포커스 처리는 구현·브라우저 검증을 통과했다. 재리뷰에서 재시도 중 안내 제목·본문·버튼이 같은 진행 상태를 반복하고, 기존 내 위치 컨트롤과 함께 status 영역 두 개가 생기는 문제를 발견했다. 이는 기존 명세의 로딩 문장 재도입 금지에 어긋난다.

## 구현 수정

버튼과 포커스 유지·중복 요청 차단은 유지하면서 진행 표시는 스피너 중심으로 정리한다. 동일 요청의 접근성 로딩 안내도 한 곳에서만 제공한다. 위치 오류의 실제 사유와 재시도 버튼, 작은 화면 내부 스크롤, 성공·실패 포커스 동작은 보존한다. 새로운 API·의존성·기능은 추가하지 않는다.

## 정확 테스트 변경

새 테스트 개수는 늘리지 않는다. 기존 승인한 mapLocationRetryPreservesFocusAcrossPendingFailureAndSuccess 한 개에서 pending 직후 다음 두 검증을 추가한다. 전체는 123개를 유지한다.

- ‘내 위치를 확인하는 중입니다.’를 포함하는 status는 정확히 하나.
- 재시도 안내 안에는 제목·본문·버튼의 중복 로딩 문장 세 표현이 없어야 함.

기존 모든 포커스·요청 수·성공·실패 기대값을 그대로 유지한 정확 본문은 pending-announcement-test.ts.txt에 있다. 다른 122개 테스트·fixture·명세·전체 테스트 명령은 변경하지 않는다.

초안을 기존 파일에 반영한 메모리상 소스의 타입·린트·Prettier 검사와 실제 소바야 파싱(5개 항목, 재검증 1개, 헤더 일치)은 통과했다. 실제 보호 테스트는 아직 변경하지 않았다.

승인 후 실제 테스트·제안 사본·failed-test.md의 동일 항목 본문을 정렬하고 해당 항목만 미완료로 바꿔 새 검증을 실행한다. 다른 완료 항목은 유지한다. 공식 재승인 후 소바야로 수정, 기존 브라우저 검증과 단일 로딩 안내 검사·123개 gate·독립 리뷰 후 dev PR까지 진행한다.
