# 상세 시트 통합 시나리오 목록

아직 테스트 코드를 한꺼번에 작성하지 않는다. 사용자가 요청한 제품 의도와 범위 재검토를 기준으로 Sobaya의 다음 테스트를 하나씩 구체화한다. 인간 소유 spec.md와 기존 테스트를 임의로 덮어쓰지 않는다.

- [ ] 직접 기사 URL의 최초 서버 HTML에 h1·요약·발행 정보·원문과 확장 상세 시트 외형을 제공한다.
- [ ] 목록에서 추가 로딩 후 상세를 열고 닫아도 같은 결과와 읽던 위치를 유지한다.
- [ ] 검색어·검색 강조·결과를 유지하며 상세를 열고 뒤로/앞으로 이동한다. 상세 메타데이터에 검색의 noindex가 남지 않는다.
- [ ] 지도 단일 마커·하단 기사 카드가 같은 상세 시트로 진입하고 SDK·중심·줌을 보존한다.
- [ ] 숫자 원2건·12건의 모든 기사를 선택할 수 있고 상세에서 지역 선택으로 복귀한다. 패널은 한 장만 보인다.
- [ ] 기본/확장·내부 스크롤·핸들·Escape·닫기에서 배경 스크롤을 차단하고 호출 요소로 포커스를 복구한다.
- [ ] 직접 공유 유입의 닫기는 앱 내부 목적지로 이동하고 새로고침에서도 기사 본문을 유지한다.
- [ ] 원문은 검증된 주소를 새 탭에서 열며 이미지 실패와 AI 표시·공유 취소·복사 실패 복구를 유지한다.
- [ ] 위치/분류/출처 데이터가 없으면 정확 주소·상태·언론사 로고·주변 사건을 만들어 표시하지 않는다.
- [ ] 존재하지 않는 기사와 API 장애를 구분하고 안전한 재시도/복귀, 올바른 robots·대표 URL·구조화 데이터를 제공한다.
- [ ] 기사별 공유 미리보기 개선을 채택하면 한국어 제목·실제 발행 정보·브랜드와 오류 응답을 검증한다.
- [ ] 전체 기존 테스트·포맷·린트·타입·빌드 및 실제 브라우저/봇 HTML 대조로 결과를 확인한다.
