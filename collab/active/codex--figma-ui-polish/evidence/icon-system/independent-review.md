# 공통 아이콘 검토

8393d30의 공통 UI 변경을 읽기 전용으로 검토했다. SVG에는 id/clipPath 충돌·viewport 잘림이 없고, 장식 의미·시간/스크린리더 텍스트·원문 URL/말줄임·pending 표시·조작 영역을 유지한다.

좁은 필터에 일반12px 화살표를 적용하면 글자와 겹칠 우려를 발견해 표시용8px 토큰과 카테고리/상태 안쪽 패딩10px로 조정했다. 24시간의 실제 폭과 줄바꿈은 production 브라우저 측정에서 별도 확인한다.

파비콘·검색 감사에서는 Apple180의 반복/잘림을 실제 배포 바이트와 픽셀에서 확인했고, ICO/SVG/OG는 정상임을 확인했다. 운영의 잘못된 기사 주소200과 PR의404 처리를 구분한다. 최종 실제 브라우저 결과는 별도 자료를 따른다.

최종 e39f의 추가 읽기 검토에서도 필수 수정 사항은 없었다. 생성기는 PNG96/Apple180만 쓰며 ICO는 기준 바이트와 같다. Chrome 회귀는 가로채기 없는 별도 컨텍스트에서4형식을 모두 디코딩하고, 각 형식의 픽셀 검사도 유지한다. PNG96은 추적해 커밋했다.
