## 해소된 검토 항목

### [해소됨, 기존 P2] 최근 기사 날짜 텍스트의 명도 대비

- 위치: `src/features/map/ui/map-carousel-card/map-carousel-card.tsx:30`
- 변경: 11px 발행일 텍스트를 `text-muted`에서 `text-slate-400`으로 변경했다.
- 영향: `bg-floating` 카드가 흰색/밝은 지도 타일 위에 놓이면 날짜를 읽기 어려워진다. 최근 기사 구역의 발행 시각은 실제 정보를 전달하므로 장식 문자 예외에 해당하지 않는다.
- 근거: 저장소의 `--color-muted`는 `#64748b`로 흰색 대비 약 **4.76:1**이다. 설치된 Tailwind의 실제 `--color-slate-400`은 `oklch(70.4% 0.04 256.788)`이고, 선형 sRGB 상대 휘도로 계산한 흰색 대비는 약 **2.63:1**이다. 일반 크기 문자에 필요한 **4.5:1**에 미달한다. [W3C WCAG 2.2, 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)
- 적용 확인: 레이아웃과 글자 크기는 유지하면서 날짜 색상이 기존 `text-muted`로 되돌아왔다. 마지막 diff에서 이 파일이 빠진 것도 확인했다.

## 추가 기능 결함 없음

정적 검토 범위에서는 위 항목 외에 확정할 수 있는 새 기능·SDK·SEO 회귀를 발견하지 못했다.

- `naver-map-sdk.ts`는 기존 네이버 SDK 타입과 스크립트 URL/키 생성을 그대로 옮겼다. Google 선택지나 가짜 동작을 추가하지 않았고 네이버 초기화·이벤트·인증 실패·재시도·정리 경로는 유지한다.
- 캐러셀은 중복 제거·발행일 정렬 뒤 4건으로 자르며, 지도 마커에 전달하는 전체 기사 데이터는 자르지 않는다.
- 검색의 추천 영역은 빈 검색에서만 표시하며, 실제 검색 결과·최근 검색 저장·무한 스크롤 데이터 계약은 유지한다. pending 스피너의 절대 위치를 사용하는 두 호출부 모두 `relative` 링크이므로 영역 이탈을 확인하지 못했다.
- 서비스 소개의 시각 레이어를 제거한 뒤 `SiteStructuredData`가 기존 WebSite JSON-LD를 유지한다. 이 컴포넌트는 클라이언트 경계 안에서도 Next의 최초 서버 렌더에 참여하며 별도 CSR 전용 로더가 없다.
- 기사 직접 URL·메타데이터·canonical·JSON-LD·404·공유 URL 처리에는 이번 작업 diff로 의미 변경이 없다.
- `/about`·`/archive`는 공개 경로·사이트맵에 남는다. 메뉴 위치가 미정인 점과 추가 안내 행 제거는 이번 요청의 명시된 결정으로 취급했다.

디자인의 픽셀 일치와 실제 기기/브라우저 조작 검증은 다른 검토자의 QA 범위이며, 이 문서는 그 실행 결과를 대신 주장하지 않는다.
