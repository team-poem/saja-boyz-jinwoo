# PR45 후속 보완 독립 검토

제품 소스 11d667e의 기존 보완과 최종 36ac745의 검색 포커스 수정을 각각 읽기 전용으로 검토했다. 수정이 필요한 새 문제는 발견하지 못했다.

- 기존 RSC·404·요청 수·타임아웃 검증을 유지한다. 목록과 검색의 320/393/1440px 실제 Tab·Shift+Tab, 상세 복귀, opener와 스크롤 복원을 검증한다. 검색은 원래 검색어도 확인한다.
- 공유 버튼과 수동 URL은 본문과 같은 스크롤 영역에 있고 포커스 순환을 유지한다. 출처는 안전한 URL·전체 접근 이름·새 탭 보호를 유지하며 밑줄을 도메인 텍스트에만 적용한다.
- 펼침 상태 보고 callback은 참조가 안정적이며 observer 루프를 만들지 않는다. 지도 DOM과 body lock 수명을 보존한다.
- 검색 44px·삭제 32px 조작 영역과 전역 포커스 윤곽, 제보 필드·첨부·제출 계약을 유지한다.
- 추가 검색 스크롤 여백은 검색 페이지의 article a에만 적용되며 검색폼·추천어·상세 시트에 영향을 주지 않는다. 기존 테스트 기대값과 시간 제한도 유지한다.
- OS별 이모지 외형과 API 미제공 정보는 CSS 차이와 구분하며 전체 픽셀 일치로 주장하지 않는다.

실제 프로덕션 캡처와 Figma 대조는 별도 브라우저 자료를 따른다. 검토자는 소스·Git·테스트·Figma를 수정하거나 외부 리뷰를 게시하지 않았다.
