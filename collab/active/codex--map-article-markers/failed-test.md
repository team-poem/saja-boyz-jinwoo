# 실제 기사 지도 연결 시나리오

- [x] 모든 페이지를 서버에서 읽고 resolved 위치가 있는 기사만 지도에 전달한다.
- [x] 계약 위반 좌표·근거·상태 및 실패/빈 페이지를 안전하게 처리한다.
- [x] 마커를 선택하면 위치 정확도와 기사 상세 링크를 표시하고 이벤트를 정리한다.
- [x] 기사 위치 보기는 전체 좌표를 포함하며 지도 기본 위치·재진입 복원을 유지한다.
- [x] API 오류/좌표 없음 상태에서도 지도와 내 위치를 사용할 수 있다.

- [x] 동일 대표 좌표의 기사는 숫자 마커로 묶고 모든 기사 상세 링크를 제공한다.
- [x] region 정확도를 별도로 수용하고 지역 대표 위치 안내를 표시한다.
- [x] SDK 인증 실패와 언마운트에서 기사 마커·리스너를 정리한다(이미 GREEN).

- [x] 지역 카탈로그를 사용할 때 기상청 좌표 출처를 표시한다.
- [x] 페이지 조회 도중 total이 변하면 불완전한 집합을 전체처럼 표시하지 않는다.
