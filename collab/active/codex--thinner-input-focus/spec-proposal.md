# 입력 포커스 윤곽 두께 조정

검색 입력, 제보 분류·일시·제목·위치·내용, 첨부 입력과 상세 공유 링크 입력에 포커스할 때 빨간 선이 겹치지 않는 1px 테두리를 표시한다. 배경색과 레이아웃은 바꾸지 않는다. 검색 입력은 바깥 폼, 첨부는 표시되는 래퍼에 적용한다. 검색 폼의 평상시 경계와 포커스 경계를 구분하고 제보 오류 상태에서도 포커스를 알아볼 수 있게 한다. 검색 초기화·파일 첨부·공유 복사와 키보드 탐색을 유지하고 버튼과 링크의 기존 포커스 표시를 바꾸지 않는다.

실제 Chrome에서 320px 및 393px 화면의 검색·제보 키보드 포커스 전후와 오류 상태를 확인하고 캡처한다. 전체 테스트, 린트, 포맷, 빌드를 실행한다.
